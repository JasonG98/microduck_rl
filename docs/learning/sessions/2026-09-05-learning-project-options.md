# 独立动作项目候选

日期: 2026-09-05. 用户已保留以下三个候选, 尚未确定最终项目或实施顺序. 目标是独立设计有挑战性的新动作, 形成可复现的开源成果. 当前处于讨论阶段, 三个候选均未开展专项物理验证、实现或训练.

## 三个方向

| 用户保留的候选 | 动作定义与学习价值 | 主要风险/待验证事项 |
|---|---|---|
| 月球漫步/滑步舞 | 身体后移, 双脚交替承重与滑动, 形成可辨认的动作风格. 学习风格约束、奖励设计、参考动作与模仿学习的取舍 | 易学成普通倒走或双脚拖行; 足底摩擦敏感; 人类脚尖支撑细节不能直接照搬. 是否采用模仿学习尚未确定 |
| 走梅花桩/精准踩点 | 先在完整平地按顺序踩中左右脚目标区域, 再扩展低矮踏块、变化步距及转弯. 学习目标条件化、课程、接触状态与泛化评估 | 单脚平衡、可达范围、踏块边缘接触待测. 速度指令不能直接表达任意足部落点, 足目标接口需要单独设计 |
| 推箱子转弯并停进目标区 (Push-T) | 当前讨论按双足机器人推动 T 形物体, 对齐目标位置和朝向理解. 学习接近、接触、推动、绕行、再接触及自身平衡 | T 形物体尺寸/质量/摩擦、接触部位、具体成功标准尚未确定. 推物反力会影响站立, 不能直接照搬固定推杆任务. 可先用准确物体位姿隔离控制问题, 再接视觉 |

## 如何比较

| 关注点 | 对应候选 | 理由 |
|---|---|---|
| 首次独立 RL 实践 | 精准踩点 | 目标误差明确, 便于从平地到踏块逐级验证 |
| 动作趣味与视频表现 | 月球漫步 | 突出动作风格和辨识度 |
| CV 与机器人操作结合 | Push-T | 可逐步加入视觉, 形成感知与接触控制项目, 系统范围较大 |

以上是导师建议, 不是已确定的实施顺序. 三个方向的机械可行性都需实测, 不预设训练一定成功.

## 评估与接口

- 月球漫步: 滑步风格、支撑切换、跌倒率; 明确与普通倒走/拖行的区别.
- 精准踩点: 落脚误差、连续踩点成功率; 区分目标控制误差与踏块接触失败.
- Push-T: 物体位置与朝向误差、完成率、机器人跌倒率; 明确允许的接触方式.

具体数值门槛待确定. 开源成果应包含训练配置、评估脚本、基线对比及成功/失败视频. 当前共享 61D actor 约束保持, 足目标和物体观测的架构需要单独设计, 不直接追加维度或改变现有槽位语义. 视觉不是第一版强制要求.
