# 面试拷问: 题库与答题记录 (quiz/)

面试拷问 (题库式测验) 是导师的正式复习/验收手段, 规则见
[SKILL.md](../../../.agents/skills/microduck-mentor/SKILL.md) 的"面试拷问模式"一节, 记录约定见
[recording.md](../../../.agents/skills/microduck-mentor/references/recording.md). 本目录只放两样东西, 职责严格分离:

## 目录职责

| 子目录 | 放什么 | 不放什么 |
|---|---|---|
| `questions/` | 可复用题库: 题面/选项/答案/考点讲解, 按主题分组 | 任何用户个人成绩或作答内容 |
| `records/` | 每次测验的作答与判定: 用户选择/对错/讲评/复测状态 | 完整题面 (用题库编号引用, 不复述) |

- 文件命名: 题库 `<单元>-bank.md`; 记录 `YYYY-MM-DD-<范围>-quiz.md`, 同天多次测验加后缀 (round-1/round-2 或主题词).
- 题目编号: 主题前缀加序号, 如 `reg-1` (注册/导入时机), `copy-1` (副本与深拷贝), `cli-1` (CLI 覆盖), `live-1` (运行中修改), `dims-1` (配置定位), `div-1` (职责分工), `unit-1` (步与单位), `onpol-1`, `cvdata-1`, `vocab-1`. 记录一律用题库编号引用.

## 判分与证据等级

- 选择题作答 = **识别级证据** (看到选项能认出对的), 不等于文字复述或独立操作级掌握. 判分与记录时如实标注, 不虚报.
- 判定只有三种: 对 / 错 / 未答 (用户答"不知道"合法, 记为未答).
- 错题与未答题进入**复测队列**; 复测必须换场景 (换数值/视角/规模/角色), 不原题重发; 该批复测全对才销项.
- 出题前用当前源码核对题干里的全部数值与符号; 选项干扰项优先取自用户真实错解, 复测题可埋入用户上次踩过的坑.
